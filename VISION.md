# Personal AI Core

## Vision

Build a personal, mobile-stable AI system that is independent of any single AI provider.

The system should eventually provide:

- one personal interface
- persistent memory owned by the user
- continuity across projects and conversations
- access to multiple AI models/providers
- intelligent model routing
- tools and external integrations
- cost-aware execution
- replaceable AI providers
- increasingly autonomous capabilities

The goal is not to build another chatbot.

The goal is to build the layer that connects the user to an ecosystem of AI models, memory and tools.

## Core Principle

The assistant should remain functional even if any single AI provider changes its pricing, availability, capabilities or policies.

Providers are replaceable components.

The personal AI system is the persistent layer.

## Current Status

Stage: 1 — Foundation

Current goal:
Establish the repository, principles and initial architecture without premature implementation.

## Non-Goals

For now, do NOT build:

- a custom foundation model
- a complex UI
- autonomous agents
- voice assistant functionality
- a huge framework
- unnecessary infrastructure

Build the smallest useful foundation first.
