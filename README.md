# PAE
Persistent Artificial Entity

Canonical source of truth for the PAE project.

PAE is a provider-independent persistent AI system whose identity, memory, project state, routing, tools and continuity should remain portable across models, providers and interfaces.

See `CANON.md`, `VISION.md`, `MEMORY.md`, `PROMISE.md`, and `architecture/v0.1/` for the current project state.
