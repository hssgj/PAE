# Concepts

This file records the concepts we have explicitly established.

## Words ≠ Meaning

Words are surface input. A semantic system maps language toward concepts and roles.

Example:

jíst / žrát / konzumovat
→ related action concept
→ EAT

## Reference resolution

A phrase may refer to something outside the literal words.

Example:

"Nessie" may refer to a specific entity known through context/memory.

"ten pes" does not automatically mean Nessie.

## Grounding

Grounding connects interpreted meaning to a specific contextual/world entity.

Unknown must remain UNKNOWN unless evidence supports the resolution.

## Memory

Information retained or available from previous context.

Example:

Nessie is a dog.

## State

The current condition of a relevant situation.

Example:

Nessie is currently vomiting.

Memory can contribute to state construction, but memory and state are not identical.

## Task vs Action

Task = what needs to be accomplished.

Action = concrete operation performed toward the task.

## Orchestration

Control over the workflow: deciding what information, retrieval, tools, questions, actions and updates are needed next.

## LLM boundary

The Playground's explicit structures are architectural abstractions.

They must not be presented as exact hidden GPT internals.
